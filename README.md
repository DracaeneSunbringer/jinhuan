# 尽欢

尽欢是一个包含图廊、聊天、社区装扮与小游戏的 Web 项目。这个仓库提供可独立使用的源码和空库结构。

| 目录 | 内容 |
| --- | --- |
| [website](website/) | 主站 Worker、图廊与聊天前端、账号系统、站内农场、庄园和街机代码 |
| [skins](skins/) | 气泡样式、通用饰件、预览页、投稿格式和校验器 |
| [mini-apps](mini-apps/) | Discourse 小程序 SDK、打砖块、2048 和能力测试台 |
| [guess-standalone](guess-standalone/) | 独立猜词运行入口、玩法引擎和自动化测试 |

自有代码采用 [MIT 许可证](LICENSE)。第三方依赖与素材使用各自的许可证，见 [第三方声明](THIRD_PARTY_NOTICES.md)。

发布包以空库启动。图廊没有预置图片。测试使用合成数据。生产账号、聊天室历史、图廊素材与链接、用户专属映射、部署秘密、生产数据库和项目内部历史都未打入此版本。部分功能需要为自己的实例配置服务或提供可再发布的素材。
