# 尽欢

尽欢包含图廊、聊天、社区装扮与鱼鱼谷。仓库提供自托管源码和新实例使用的空库结构。

| 目录 | 内容 |
| --- | --- |
| [website](website/) | 主站 Worker、图廊与聊天前端、账号系统和鱼鱼谷网页版 |
| [skins](skins/) | 气泡样式、通用饰件、预览页、投稿格式和校验器 |
| [fish-valley](fish-valley/) | 鱼鱼谷的小程序客户端、打包入口与沙箱接入适配 |

新实例的用户、会话、群聊、私信和图廊数据为空。图廊图片和原图链接由各自运营的实例管理。自有代码采用 [MIT 许可证](LICENSE)，第三方依赖及鱼鱼谷地图素材遵循 [各自的许可](THIRD_PARTY_NOTICES.md)。

## 参与贡献

通过 [Issues 提需求](https://github.com/kourou25/jinhuan/issues/new/choose)。[社区更新投稿](contributions/README.md)通过格式检查后会自动合并并同步到线上。
